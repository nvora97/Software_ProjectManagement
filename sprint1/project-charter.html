Project Charter

CampusCents is a personal finance management system designed to help college students manage their income, expenses, budgets, bills, and savings goals.

Download the Project Charter PDF

Project Purpose

Many college students have difficulty understanding where their money goes and how much they can safely spend each month. CampusCents will provide a simple system where students can record transactions, create budgets, monitor spending, receive bill reminders, and track savings progress.

Project Objectives

  • Allow users to record income and expenses.
  • Help users create and manage monthly budgets.
  • Display spending by category.
  • Allow users to create and monitor savings goals.
  • Provide reminders for upcoming bills.
  • Present simple financial summaries and reports.

Project Scope

In Scope

  • User profile creation
  • Manual income and expense entry
  • Customizable spending categories
  • Monthly budget creation
  • Budget and spending dashboard
  • Savings-goal tracking
  • Bill reminders
  • Basic financial reports
  • Responsive web design

Out of Scope

  • Direct connections to bank accounts
  • Payment processing
  • Investment recommendations
  • Tax preparation or tax advice
  • Credit-score calculations
  • Cryptocurrency trading
  • Loans or lending services

Major Deliverables

  • Living Project Portal
  • Project requirements and prioritized backlog
  • Finance management system prototype
  • Budgeting and expense-tracking features
  • Testing results and supporting evidence
  • User documentation
  • Sprint records and final project demonstration

Assumptions

  • Users will have reliable internet access.
  • Users will enter their financial information manually.
  • The team will use free development and hosting tools.
  • The prototype will not use real banking information.
  • Team members will review shared work before submission.
  • Course deadlines will determine the project schedule.

Constraints

  • The project must be completed within one semester.
  • The team has no budget for paid services.
  • Team members have limited and different schedules.
  • Financial information requires careful privacy protection.
  • The system cannot provide professional financial advice.

Stakeholder Register

Stakeholder Interest Influence Planned Engagement
College students Simple budgeting and useful financial feedback High Interviews and usability testing
Instructor or project sponsor Complete and defensible project work High Sprint reviews and portal updates
Project team Clear responsibilities, scope, and schedule High Weekly meetings and task reviews
University community Support for student financial wellness Medium Feedback on usefulness and accessibility
Future developers Understandable code and documentation Medium Repository documentation and change history

Key Project Risks

  • Scope growth: Additional features could delay the project.
  • Calculation errors: Incorrect financial calculations could reduce user trust.
  • Privacy concerns: Financial information must be handled carefully.
  • Unclear responsibilities: Poor task ownership could cause missed deadlines.
  • Limited user feedback: The design may not meet student needs without early testing.

Success Criteria

  • The core budgeting and expense features work correctly.
  • Financial calculations are accurate during testing.
  • Users can understand and complete the main tasks.
  • The required portal documents are complete.
  • The project remains within the approved scope.
  • Every team member can explain the project decisions.
